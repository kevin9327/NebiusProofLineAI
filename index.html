    2. Developer Friction & Edge Cases Observed
    
          
      
            
    • <think> Block vs. Structured JSON Output: When calling reasoning-enabled Nemotron endpoints at temperature=0.2 with response_format={"type": "json_object"}, the stream occasionally prepends <think>...</think> tokens prior to the opening { brace. We built a deterministic stream splitter that strips and logs the <think> trace separately before `json.loads()`.
      • 
            
    • Token Usage Breakdown for Reasoning Tokens: Exposing `usage.completion_tokens_details.reasoning_tokens` consistently across all Nemotron-3 tiers in Nebius Token Factory responses makes FinOps attribution significantly easier.
      •
